Office Escape

Friday, 6:05 p.m. Your intern badge has expired. The night technician left a key at each workstation. Five doors stand between you and the weekend.

How to play

Find one key at each workstation. Opening the fifth door lets you escape.

1. Look around. In the Terminal, type ls (lowercase L and S) and press Enter to list the files.

2. Read a file. At Reception, try cat hours.txt. Then use cat with another filename to look for the key.

3. Open the door. Copy the key from the file into the Door keypad and select Unlock door.

You can retry a command or key. Type help for command examples, or select Get a nudge for a clue. Each room offers three hints. The last one gives the answer.
