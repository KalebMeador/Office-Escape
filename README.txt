OFFICE ESCAPE!
Created by Kaleb Meador

ABOUT THE GAME
It's Friday evening, and your intern badge has expired. The night technician
left a key at each workstation. Search the files, unlock all five doors,
and escape the office.

Five Doors is a browser game for people learning Linux terminal commands
for the first time. The terminal uses a simulated filesystem inside the game.

HOW TO PLAY
1. At Reception, type ls in the Terminal and press Enter to list the files.
2. Use cat followed by a filename to read a file and look for the door key.
3. Enter the key in the Door keypad and select Unlock door.
4. Repeat until you open the fifth door and escape through the lobby.

COMMAND GUIDE
ls                    List files and folders.
cat filename          Read a file.
cd folder             Move into a folder.
cd ..                 Move up one folder.
grep WORD filename    Show lines in a file that contain WORD.

New commands appear as you progress. Type help to see the commands available
in your current room. Select Need a clue? to reveal hints one at a time.

PROGRESS
The game saves progress in your browser when local storage is available.
After escaping, open the practice breakdown to review time, commands,
mistakes, and hints for each door.
